# DeutschFlow v2

تطبيق محلي لتعلّم الكلمات الألمانية بالعربية.

## التشغيل

### أسهل طريقة
افتح `DeutschFlow-Standalone.html` مباشرة بالضغط المزدوج. هذه النسخة تعمل دون خادم ودون إنترنت.

### نسخة PWA القابلة للتثبيت
شغّل خادماً محلياً داخل مجلد البرنامج:

```bash
python -m http.server 8000
```

ثم افتح:

```text
http://localhost:8000
```

يمكن بعدها تثبيت التطبيق من زر **تثبيت التطبيق** أو من قائمة المتصفح.

## التحسينات الرئيسية

- فصل الكلمات الأساسية عن المحاولات والإعادات في العد.
- عدم إظهار النطق في سؤال العربية ← الألمانية إلا عند طلب التلميح.
- مراجعة متباعدة مستقلة لكل مهارة.
- بطاقات منفصلة للاستدعاء، التعرّف، الأدوات، وترتيب الجمل.
- استيراد حقيقي من XLSX وCSV.
- تصحيح علامات الترقيم، Umlaut، الأدوات، حالة الأحرف، والأخطاء الإملائية.
- نقل تلقائي محتمل لتقدم النسخة السابقة عند التشغيل على نفس أصل المتصفح.
- قاعدة بيانات محلية IndexedDB ونسخة احتياطية JSON كاملة.
- PWA تعمل دون إنترنت.

## ملاحظة البيانات

تم الاحتفاظ بقاعدة الكلمات الأصلية وإضافة فحص آلي لجودة البيانات. إشارات الجودة لا تعني أن كل مدخل معلّم خاطئ لغوياً؛ بل يحتاج إلى مراجعة بشرية.
